# How Neural Networks Work

Neural networks are the backbone of modern AI, inspired by the human brain.  
They learn to recognize patterns in data by adjusting connections between neurons.

## 1. Basic Structure

- **Neurons (Nodes)**: Basic units that process data  
- **Layers**:
  - Input layer: receives data  
  - Hidden layers: process data  
  - Output layer: generates prediction

- **Weights**: Control the influence of inputs  
- **Bias**: Helps the network fit the data  
- **Activation Function**: Adds non-linearity (e.g., ReLU, Sigmoid)


## 2. How They Learn

1. Input data is passed forward (Forward Propagation)  
2. Network makes a prediction  
3. Error is calculated (Difference between prediction & actual)  
4. Backpropagation adjusts weights to reduce error  
5. Repeat until the network learns


## 3. Example

- Task: Recognize handwritten digits (0–9)  
- Input: Pixel values of images  
- Output: Predicted digit


## Conclusion

Neural networks can solve complex tasks like:
- Image recognition
- Speech recognition
- Natural language understanding

Understanding the intuition is more important than math when starting.
