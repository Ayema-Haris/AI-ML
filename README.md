## ⚙️ Getting Started

> *“Every expert was once a beginner.”*

### Prerequisites

* Python 3.8+
* pip or conda

### Installation

```bash
git clone https://github.com/smartly-creators-program/AI-ML.git
cd AI-ML
pip install -r requirements.txt
```

## ▶️ Usage

Run experiments:

```bash
jupyter notebook
```

Train models:

```bash
python scripts/train.py
```

Evaluate models:

```bash
python scripts/evaluate.py
```
